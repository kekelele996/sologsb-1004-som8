# 博物声 · 博物馆展陈脚本工作台

面向博物馆内容团队的展陈脚本编写、审校与版本管理工具。项目按“展厅 → 展项 → 语言”组织内容，覆盖标题、讲解词、无障碍描述、朗读时长和资料来源。

## 功能

- 展厅、展项切换，以及中文、英文、日文多语言稿件进度对照。
- 草稿、待审、退回、待同步、已定稿五态流转；每个展项挂中文主稿版本，中文定稿后再改动会回到待审，已定稿译文自动转“待同步”且译文不丢。
- 待同步译文按字段与段落列出和中文稿不一致之处，逐段确认后才能重新定稿；译文锁定段落保留原内容，标记“锁定保留”，其余段落列为待处理。
- 左侧导航与编辑页直接显示待同步语言及待确认数量；同步基线、确认进度随本地数据持久化，重新打开工作台关系仍在。
- 已确认段落可锁定，避免误改。
- 分段校对、预计朗读时长、自动字数/语速估算和来源核验。
- 完整版本快照、句子级差异比较和版本恢复。
- 桌面、平板、手机、馆内触摸屏四种排版预览。
- 浏览器本地持久化，刷新后恢复；最多 50 步撤销重做。
- `Ctrl/⌘ + Z`、`Ctrl/⌘ + Shift + Z`、`Ctrl/⌘ + S` 快捷键与语义化表单标签。

## 技术栈

- Nuxt 3、Vue 3、TypeScript、Pinia
- Vuetify 3
- 浏览器 `localStorage`

## 本地开发

```bash
npm install
npm run dev
```

开发服务器默认监听 `http://localhost:3000`。应用不包含宿主端口配置。

## 生产构建

```bash
npm install
npm run build
```

静态产物位于 `.output/public`。可用 `npm run preview` 预览。

## Docker

```bash
docker build -t sologsb-1004 .
docker run --rm -p 10004:80 sologsb-1004
```

容器内 nginx 监听 80，静态单页回退到 `index.html`。根据根端口表，本地映射为宿主 `10004`。

## 数据说明

所有数据只保存在当前浏览器。清除站点数据会删除本地稿件；版本快照保存在同一份本地数据中。
